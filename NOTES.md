- Unity now crashes entirely if DX11 is active. Make sure to deactivate Auto Graphics API for Windows and make sure only DX12 and/or Vulkan are active.

---

Main optimization options:
  1. Spatial hierarchy / chunk culling
      - Group Gaussians into spatial nodes.
      - Cull whole nodes first.
      - Process individual Gaussians only inside visible nodes.
      - Biggest direct improvement to current frustum-culling implementation.
      - Highest complexity; needs robust XR-aware bounds.
  2. LOD
      - Alters image quality; needs measurable error/quality controls.
  3. Overdraw reduction
      - Reduce fragments generated by large or overlapping visible splats.
      - Important because profiling showed drawing/fragment work remains dominant.
      - Possible approaches: footprint limits, hierarchical rendering, better rejection, tile-based processing.
      - Some methods change appearance or require substantial renderer redesign.
  4. Opacity pruning
      - Skip Gaussians whose effective contribution is negligible.
      - Could happen during import, runtime selection, or both.
      - Smaller implementation; potential asset-quality tradeoff.
      - Best treated separately from pure frustum culling.
  5. Chunk streaming
      - Keep only nearby/relevant spatial chunks resident or active.
      - Helps VRAM, loading, and massive scenes.
      - More asset-pipeline and lifecycle work than frame-only optimization.
